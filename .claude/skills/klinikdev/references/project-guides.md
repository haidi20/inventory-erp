# Project Guides

Gunakan file panduan proyek berikut bila task membutuhkan detail tambahan:

- `guides/step_dev_feature_guide.md`
- `guides/step_fe_feature_guide.md`
- `guides/structure_guide.md`

Baca file-file ini bila:
- perlu mencocokkan struktur folder fitur dengan standar proyek
- perlu memastikan urutan implementasi backend dan frontend
- perlu menyesuaikan detail TDD atau pola modular yang sudah dipakai tim
